description: Instruction on how to generate sound effects using ElevenLabs API.
---

- Generate sound effects using ElevenLabs sound effect generation functionality.
- Use detailed prompts.
- Specify the desired audio length explicitly.
- Use multiple versions for the sounds effects in the game.
- Use `ELEVENLABS_KEY` from `.env` file for the API access.
